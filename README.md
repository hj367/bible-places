# All Bible Places

An interactive atlas of every place named in the Bible: where scholars locate it, how confident they are, and every passage that mentions it.

Live atlas: https://hj367.github.io/bible-places/

Google Earth: [all-bible-places.kmz](all-bible-places.kmz) (or the plain [KML](all-bible-places.kml)) has every located place, coloured by kind, plus region and river outlines.
